# Artefatos de execução documental

Organização proposta: `runs/AAAA-MM-DD/identificador/`. Somente conteúdo sintético ou documental sem dados pessoais. Outputs de casos reais pertencem a armazenamento clínico restrito, fora deste repositório.

O `.gitignore` evita inclusão casual dos runs locais; não é mecanismo de anonimização nem substitui revisão antes de commit.
